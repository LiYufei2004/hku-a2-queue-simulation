System parameters

Entry arrivals (NHPP)

Arrivals enter from either side, then choose a queue. Each entry receives the additional surge rate during class-ending windows. Set the repeat interval to 0 for a single surge. The 60-minute default is retained from the previous version.

Choice and walking

β = 0 gives a 50/50 split. Higher values favor shorter expected delays. Decisions start at the local queue tail: staying adds no walking; switching takes ℓ × (N_left + N_right) / speed. Map mode is an optional comparison. No crowd slowdown is applied.

PDF equations (5)–(9): position loss ΔN = λ_queue(t) × walking time; expected delay = walking + ceil((N + ΔN + 1) / mean capacity) × (cycle / 4). Destination arrival rates combine both entry rates with their latest choice probabilities, held at the decision time. Real boarding uses independent lift events. The lookup table uses this same cost function.
